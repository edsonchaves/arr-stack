# Jellystat Setup

**URL:** `http://localhost:8288`

1. Create an admin account on first launch
2. Settings → Jellyfin Connection → fill in:
   - Jellyfin URL: `http://jellyfin:8096`
   - API Key: create a dedicated key in Jellyfin → Admin Dashboard → API Keys → `+` → name it `jellystat`
3. Save — Jellystat will start pulling watch history automatically
